# Treinamento: Introduçào à Automação de Testes

## Automação Web

Escrita do primeiro teste automatizado E2E, deste treinamento. Foi desenvolvido utilizando **Cypress** na aplicação **Sauce Demo**.

### Fluxo do teste

- Acessar a página [https://www.saucedemo.com](https://www.saucedemo.com])
- Preencher os campos de login (usuário e senha)
- Acessar a aplicação
- Validar se o login foi realizado com sucesso, verificando se a URL contém `/inventory.html`

### Tecnologias utilizadas

- JavaScript
- Cypress
